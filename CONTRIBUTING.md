# Mitwirken

1. Erstelle einen Branch mit dem Präfix `codex/` oder einen beschreibenden
   Feature-Branch.
2. Ergänze Tests für Parsing und Entitäten.
3. Führe mindestens `python -m compileall custom_components/sicce_contrall`
   und `git diff --check` aus.
4. Dokumentiere jede neue, verifizierte API-Annahme in
   `docs/PROTOCOL_RESEARCH.md`.

Pull Requests mit Pumpen-Schreibzugriff benötigen einen nachvollziehbaren
Nachweis des Request-Formats und eines erfolgreichen Readbacks. Keine echten
Zugangsdaten in Commits, Tests, Screenshots oder Issues ablegen.
